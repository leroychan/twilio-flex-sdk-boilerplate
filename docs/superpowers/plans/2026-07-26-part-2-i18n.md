# Part 2 — i18n Foundation — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add next-intl to the Part 1 App Router shell so every UI string is translatable, ship `en` + a Spanish (`es`) stub, provide a header locale switcher that changes language at runtime (cookie-persisted, no full page reload), and enforce translation coverage with an ESLint rule that flags literal JSX text.

**Architecture:** next-intl runs in "without i18n routing" mode — the active locale lives in a `NEXT_LOCALE` cookie (not the URL). A `getRequestConfig` handler reads that cookie and builds the messages object through a **namespaced loader** (`loadMessages`) that scans two roots: core/shell namespaces at `src/i18n/messages/<locale>/<namespace>.json` (keyed by filename) and per-feature namespaces at `src/features/<feature>/messages/<locale>.json` (keyed by directory name). The loader is dynamic, so later feature parts add only their own `messages/<locale>.json` file with zero edits to Part 2's files. The root layout wraps the tree in `NextIntlClientProvider`; components read strings via `useTranslations('<namespace>')`. A client `LocaleSwitcher` writes the cookie through a server action and calls `router.refresh()` to re-render server components in place. `eslint-plugin-react`'s `react/jsx-no-literals` (already available through `eslint-config-next`) flags any untranslated JSX text in `src/**` (excluding tests).

**Tech Stack:** next-intl (v3.x+, App Router), Next.js 15, React, TypeScript, Vitest + @testing-library/react, ESLint flat config (`eslint.config.mjs`).

## Global Constraints

- Package manager: npm. Tests run via `npm run test:run` (Vitest, jsdom, `@testing-library/react`). Alias `@/` → `src/`.
- Next.js 15 App Router + TypeScript, strict mode; every user-facing string reachable via `useTranslations`.
- i18n library is **next-intl**. Locale is persisted in the `NEXT_LOCALE` cookie (constant `LOCALE_COOKIE` in `src/i18n/config.ts`); switching must NOT trigger a full page reload (`router.refresh()` only).
- Ship exactly two locales in this part: `en` (default, listed first) and `es` (stub).
- **Namespace ownership contract:** core/shell strings live at `@/i18n/messages/<locale>/common.json`; each feature owns `@/features/<feature>/messages/<locale>.json`. The loader keys core files by filename (`common.json` → namespace `common`) and feature files by feature-directory name. Access pattern is always `useTranslations('<namespace>')`. The loader must return only the available namespaces and must not throw when `src/features` is absent — later parts add feature catalogs with zero edits to Part 2's files.
- **File ownership (Part 2):** owns `src/i18n/**`, `src/components/i18n/**`, and ESLint config additions in `eslint.config.mjs`. May modify `next.config.ts`, `src/app/layout.tsx`, `src/app/page.tsx`, and `src/components/layout/AppHeader.tsx` (Part 2 is the i18n integrator). Do not modify other Part 1 files.
- Tailwind utilities available from Part 1: `bg-bg`, `bg-surface`, `bg-surface-2`, `border-border`, `text-text`, `text-muted`, `bg-primary`/`hover:bg-primary-hover`, `bg-danger`. Dark mode via next-themes class strategy.

- [ ] **Step 10: Write `src/i18n/loadMessages.ts`**

```ts
import fs from 'node:fs';
import path from 'node:path';

export type Messages = Record<string, Record<string, unknown>>;

export interface LoadMessagesOptions {
  /** Directory that contains one folder per locale of core namespace files. */
  coreDir?: string;
  /** Directory that contains one folder per feature. */
  featuresDir?: string;
}

function readJson(file: string): Record<string, unknown> {
  return JSON.parse(fs.readFileSync(file, 'utf8')) as Record<string, unknown>;
}

/**
 * Builds the next-intl messages object for a locale by merging:
 *  - core namespaces: <coreDir>/<locale>/<namespace>.json  (namespace = filename)
 *  - feature namespaces: <featuresDir>/<feature>/messages/<locale>.json (namespace = feature dir)
 * Missing directories contribute no keys and never throw, so feature parts can
 * add their own catalogs with zero edits to this file.
 */
export function loadMessages(locale: string, options: LoadMessagesOptions = {}): Messages {
  const coreDir = options.coreDir ?? path.join(process.cwd(), 'src/i18n/messages');
  const featuresDir = options.featuresDir ?? path.join(process.cwd(), 'src/features');
  const messages: Messages = {};

  const localeCoreDir = path.join(coreDir, locale);
  if (fs.existsSync(localeCoreDir)) {
    for (const file of fs.readdirSync(localeCoreDir)) {
      if (file.endsWith('.json')) {
        const namespace = path.basename(file, '.json');
        messages[namespace] = readJson(path.join(localeCoreDir, file));
      }
    }
  }

  if (fs.existsSync(featuresDir)) {
    for (const feature of fs.readdirSync(featuresDir)) {
      const file = path.join(featuresDir, feature, 'messages', `${locale}.json`);
      if (fs.existsSync(file)) {
        messages[feature] = readJson(file);
      }
    }
  }

  return messages;
}
```

```ts
export default getRequestConfig(async () => {
```

```ts
'use server';

import { cookies } from 'next/headers';
import { isLocale, LOCALE_COOKIE, type Locale } from './config';

const ONE_YEAR_SECONDS = 60 * 60 * 24 * 365;

export async function setLocale(locale: Locale): Promise<void> {
  if (!isLocale(locale)) return;
  const store = await cookies();
  store.set(LOCALE_COOKIE, locale, {
    path: '/',
    maxAge: ONE_YEAR_SECONDS,
    sameSite: 'lax',
  });
}
```

```tsx
'use client';

import { useTransition } from 'react';
import { useLocale, useTranslations } from 'next-intl';
import { useRouter } from 'next/navigation';
import { locales, type Locale } from '@/i18n/config';
import { setLocale } from '@/i18n/setLocale';

export function LocaleSwitcher() {
  const activeLocale = useLocale();
  const t = useTranslations('common');
  const router = useRouter();
  const [isPending, startTransition] = useTransition();

  function onChange(event: React.ChangeEvent<HTMLSelectElement>) {
    const next = event.target.value as Locale;
    startTransition(async () => {
      await setLocale(next);
      router.refresh();
    });
  }

  return (
    <select
      aria-label={t('localeSwitcher.label')}
      value={activeLocale}
      disabled={isPending}
      onChange={onChange}
      className="rounded-md border border-border bg-surface px-3 py-2 text-text hover:bg-surface-2 disabled:opacity-50"
    >
      {locales.map((locale) => (
        <option key={locale} value={locale}>
          {t(`localeSwitcher.locale.${locale}`)}
        </option>
      ))}
    </select>
  );
}
```

```ts
import { describe, it, expect } from 'vitest';
import { ESLint } from 'eslint';

const eslint = new ESLint({ cwd: process.cwd() });

async function ruleIds(code: string): Promise<string[]> {
  const results = await eslint.lintText(code, {
    filePath: 'src/__lint_fixtures__/Sample.tsx',
  });
  return results[0].messages
    .map((m) => m.ruleId)
    .filter((id): id is string => id !== null);
}

describe('react/jsx-no-literals enforcement', () => {
  it('flags untranslated literal JSX text', async () => {
    const ids = await ruleIds('export const A = () => <div>Untranslated</div>;\n');
    expect(ids).toContain('react/jsx-no-literals');
  });

  it('accepts JSX whose text comes from a t() call', async () => {
    const ids = await ruleIds(
      'export const A = ({ t }: { t: (k: string) => string }) => <div>{t("app.title")}</div>;\n',
    );
    expect(ids).not.toContain('react/jsx-no-literals');
  });
});
```
